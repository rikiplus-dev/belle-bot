# בלבוט 🐶 (bellebot)

בוט טלגרם משפחתי לאילוף של בל: מתעדים טיולים, פיפי וקקי (בחוץ מול בבית), אוכל והכנת אוכל, וצוברים כוכבים. יש גם לוח בקרה (Mini App) שנפתח מתוך טלגרם.

הכול רץ בחינם: Cloudflare Workers + D1 (מסד נתונים), ופריסה אוטומטית מ-GitHub Actions.

## הקמה חד-פעמית (כ-15 דקות)

### 1. בוט בטלגרם
1. בטלגרם פתחו שיחה עם `@BotFather` ושלחו `/newbot`.
2. בחרו שם (בלבוט) ושם משתמש שמסתיים ב-`bot`.
3. שמרו את ה-**token** שקיבלתם.
4. לתמונת הפרופיל: `/setuserpic` ואז הקובץ `docs/bell-bot-avatar.png`.

### 2. Cloudflare
1. הירשמו בחינם ב-cloudflare.com.
2. ב-Workers & Pages בחרו תת-דומיין (workers.dev) כשמבקשים. זה חד-פעמי.
3. את **Account ID** מוצאים בלוח הראשי של Workers & Pages.
4. צרו API Token ב-My Profile > API Tokens > Create Token > Custom, עם ההרשאות:
   - Account / Workers Scripts / Edit
   - Account / D1 / Edit

### 3. סודות ב-GitHub
במאגר: Settings > Secrets and variables > Actions > New repository secret. צרו חמישה:

| שם | ערך |
|---|---|
| `CLOUDFLARE_API_TOKEN` | הטוקן מסעיף 2 |
| `CLOUDFLARE_ACCOUNT_ID` | ה-Account ID |
| `BOT_TOKEN` | הטוקן מ-BotFather |
| `WEBHOOK_SECRET` | מחרוזת אקראית ארוכה (אותיות ומספרים) |
| `FAMILY_CODE` | קוד משפחתי שתבחרו. כל בן בית יקליד אותו פעם אחת בבוט |

### 4. פריסה
דחפו ל-`main` (או Actions > Deploy > Run workflow). הפריסה יוצרת את מסד הנתונים, מעדכנת טבלאות, מפרסמת, ומחברת את הבוט לטלגרם, כולל תפריט הפקודות וכפתור לוח הבקרה.

### 5. שימוש
כל בן בית פותח את הבוט, שולח `/start`, מקליד את הקוד המשפחתי ובוחר מי הוא.

## איך זה עובד
- **טיול הוא מפגש**: פיפי וקקי בחוץ אפשר לתעד רק בזמן טיול, והם נשמרים בתוכו. טיול שנשכח פתוח נסגר אוטומטית אחרי שעתיים.
- **תקלות בבית** (פיפי/קקי בבית) לא מזכות בכוכבים.
- **כוכבים**: טיול, פיפי/קקי בחוץ והכנת אוכל. סיכום שבועי נשלח בימי ראשון בבוקר.
- תזכורות: אחרי טיול ללא אוכל, ואם עבר זמן רב מדי בלי טיול. שעות שקט 22:00-07:00. אפשר לשנות בהגדרות (`/settings`).

## עדכון אחורה
בלוח הראשי: **🕐 שכחתי לעדכן** (או `/late`). אפשר להוסיף טיול שהיה (עם פיפי וקקי ומשך), פיפי או קקי בבית, ארוחה או הכנת אוכל, עד יממה אחורה, וגם על שם מישהו אחר. שאר המשפחה מקבלת הודעה על כל עדכון אחורה.

## בריאות
רק אמתי וריקי רואים ומעדכנים (`ADMINS` ב-`src/config.js`). **🩺 בריאות** בלוח הראשי או `/health`:
- **תרופות**: שאלון בלחצנים: שם, מינון, כמה פעמים ביום (עם שעות שאפשר לשנות) ולמשך כמה זמן. הבוט שולח תזכורת בשעה עם כפתורי "✅ ניתנה" ו-"⏭ דילגנו", ותזכורת שנייה אחרי חצי שעה אם לא עודכן.
- **שאלון בלחצנים** (בלי להקליד): **⏰ תזכורת עתידית** (סוג, אירוע, מתי) או **➕ אירוע שהיה** (סוג, אירוע, תאריך, מתי לחזור, הערה). חיסון, תילוע, פרעושים וקרציות, בדיקת דם, ביקור וטרינר, ניתוח או עיקור. אפשר גם להקליד תאריך או שם משלכם בכל שלב.
- **תזכורות**: שבוע לפני, ביום עצמו, ופעם אחת אם המועד עבר. בהתראה יש **✅ בוצע** (מתעד ושואל מתי לחזור), **⏳ בעוד שבוע** ו-**📅 הוספה ליומן**.
- **הוספה ליומן בטלפון**: קישור ליומן גוגל וקובץ `.ics` שנפתח ביומן של אייפון ואנדרואיד, עם התראה יום לפני ובבוקר המועד. זה זמין אחרי שמירה, ב-**📅 מועדים קרובים** ובהתראות.
- הגדרות הבוט (`/settings`) גם הן רק לאמתי וריקי.

## שעות אחריות, הודעות טיול ועידוד
- **שעות אחריות** (בהגדרות, לאמתי וריקי): שאלון בלחצנים: מי, באילו ימים, מאיזו שעה ועד איזו שעה. בזמן הזה רק מי שבאחריות מקבל תזכורות אילוף. מחוץ לשעות האחריות התזכורות מגיעות לכולם.
- **הודעות טיול**: כולם מקבלים "שולי הוציאה את בל לטיול" ובסיום "בל עשתה קקי, לא פיפי". אילו שמות בלשון נקבה או זכר נקבע ב-`g` בתוך `MEMBERS` ב-`src/config.js`. בלי `g` הניסוח ניטרלי.
- **עידוד מתחת להודעת הטיול**: כשמגיעה הודעה כמו "אמתי הוציא את בל לטיול", מתחתיה יש 👏 כל הכבוד, 🙏 תודה, ו-🎨 סטיקר או הודעה (שולחים סטיקר או כותבים הודעה, והבוט מעביר אותם).
- **💌 עידוד** (או `/cheer`): הודעה מוכנה, הודעה חופשית או סטיקר לבן בית או לכולם. את ההודעות המוכנות משנים ב-`CHEERS`.

## מה מותר לבל לאכול
**🍖 מה מותר לבל לאכול?** בלוח הראשי, או `/food`. פתוח לכל בני הבית.
- שלוש רשימות: **🚫 אסור**, **⚠️ בינוני** (אפשר, אבל לא בהגזמה) ו-**✅ בכיף**, עם הסבר קצר לכל מזון.
- **🔎 בדיקה של מזון**: לוחצים וכותבים שם בחופשיות ("בננה", "האם מותר שוקולד לבן?", "עוגת גבינה"). הבוט מבין ריבוי, אותיות שימוש (ה, ב, ל) וטעויות כתיב קטנות, ועונה אסור, בינוני או מותר. מזון לא מוכר מקבל "אני לא מכיר, לא נותנים ושואלים וטרינר". קיצור: `/food בננה`.
- המאגר בקובץ `src/foods.js` (שורה לכל מזון: רמה, שם, כינויים, הערה). אפשר להוסיף שורות. מבוסס על ASPCA, PetMD, AKC, Pet Poison Helpline ועוד, ואינו תחליף לוטרינר.

## הכול על בל
➕ **עוד** ← **🐶 הכול על בל** (או `/bell`):
- **📇 תעודת בל**: תאריך לידה (בבחירת גיל או תאריך), שבב, רישיון, וטרינר וטלפון. עורכים אמתי וריקי.
- **⚖️ משקל** (גם `/weight 2.4`): לחצנים לפי המשקל הקודם, או הקלדה עם תאריך אחורה (`2.4 12.10`), עם גרף.
- **🎓 חיברות** ו-**🗣 פקודות**: צ'קליסט שמסמנים בלחיצה. הפקודות עוברות לומדת, מבינה, אמינה.
- **💡 טיפים וכיף**: טיפי אילוף ועובדות על שיצו (`src/tips.js`). טיפ אחד מצורף גם לסיכום השבועי.
- **📈 ניתוח ותובנות**: אחוז הצלחות בחוץ, שעות תאונות, רצף ימים בלי תאונה, ומה הבוט למד.
- **📄 דוח מלא לווטרינר** (אמתי וריקי): קובץ להדפסה עם פרטי בל, משקל, חיסונים וטיפולים שבוצעו, מועדים קרובים, תרופות ו-14 הימים האחרונים.
- **חיסונים וטיפולים**: **💉 תיעוד חיסון שהיה** מזין היסטוריה (תאריך, ומתי לחזור), ו-**⏰ תזכורת עתידית** ב-🩺 בריאות רושמת מועד לפי הוראת הווטרינר, עם תזכורת ואפשרות להוסיף ליומן בטלפון.

## תזכורות חכמות
זמן התזכורת אחרי ארוחה נלמד מהיסטוריית בל (כשיש לפחות 6 ארוחות), והמרווח בין יציאות לפי הגיל (בערך שעה לכל חודש). בהגדרות אפשר לעבור לערך קבוע וחזרה לאוטומטי. כל 3, 7, 14, 30, 60 ו-100 ימים בלי תאונה נשלחת חגיגה.

## נוחות
- לוח ראשי מקוצר, ו-**➕ עוד** לשאר. כפתור **↩️ בטל** מראה מה יבוטל. הלוח מוצמד בצ'אט ומתחלף בכל `/menu`.
- הודעות טיול נשלחות בשקט ומתעדכנות בסיום, כך שיש התראה אחת לטיול.
- אפשר לכתוב חופשי: "פיפי בבית לפני חצי שעה", "בל אכלה", "יצאנו לטיול", "חזרנו", "האם מותר בננה?".
- **כפתור "📋 תפריט" קבוע** בתחתית הצ'אט: נוסף אוטומטית בפעם הראשונה שמקבלים את הלוח (`/menu`). לחיצה עליו מביאה את הלוח המוצמד מחדש.
- **`/as שרולי`** (אמתי וריקי): לתעד בשם בן בית אחר, למשל ילד בלי טלפון. כל מה שמתעדים נרשם עליו, כולל כוכבים. `/as אני` חוזר לעצמכם. המצב נסגר לבד אחרי 20 דקות בלי פעולה. אותו דבר זמין מכפתור "👥 לתעד בשם מישהו אחר" בלוח ובשורת "לתעד בשם" בלוח הבקרה.
- **`/weblink שולי`** (אמתי וריקי): קישור אישי ללוח הבקרה בדפדפן, לבן בית בלי טלגרם. הוא מאפשר לתעד טיולים, פיפי, קקי ואוכל ולראות הכול. שליחה חוזרת מבטלת את הקישור הישן.
- **`/invite`** (אמתי וריקי): קישור הזמנה לבן בית חדש, ואחרי ההרשמה סיור קצר. הרשמה כמנהל או על שם תפוס דורשת אישור של מנהל.
- התראת תקלה נשלחת לאמתי וריקי, ועדכונים כפולים מטלגרם נחסמים.
- לוח הבקרה: כרטיס "עכשיו", גרף משקל, בדיקת מזון, וכפתור A+ להגדלת הכתב.

## שינויים נפוצים
כל ההגדרות ב-`src/config.js`: שמות בני הבית, סוגי הפעולות, כמה כוכבים כל אחת שווה, ברירות מחדל לתזכורות. אחרי שינוי, דחיפה ל-`main` מפרסמת אוטומטית.

## פיתוח מקומי
```
npm install
npm test        # בדיקות לוגיקה
npm run e2e     # בדיקות מקצה לקצה מול wrangler מקומי
npm run dev     # שרת מקומי (העתיקו .dev.vars.example ל-.dev.vars)
```

## פרטיות
המאגר ציבורי כברירת מחדל ומכיל תמונות של בל ושמות פרטיים של בני הבית. אפשר להפוך אותו לפרטי ב-Settings > General > Danger Zone. Actions ממשיכים לעבוד בחינם.
